# KommuneKompasset 🧭

Et gruppeprosjekt som visualiserer nøkkeltall fra norske kommuner, med mål om å gjøre data mer tilgjengelig for **kommuneplanleggere og beslutningstakere**.

## Hva prosjektet inneholder

* **Kartvisning:** Oversikt over kommuner i Norge
* **Hover-data:** Rask innsikt direkte fra kartet
* **Detaljside:** Utvikling i én kommune (befolkning, bolig, m.m.)
* **Sammenligning:** Sammenligne flere kommuner over tid

## Hvorfor

Offentlig data finnes, men er ofte tungt å bruke.
Dette prosjektet gjør det enklere å:

* oppdage trender
* sammenligne kommuner
* støtte datadrevne beslutninger

## Teknologi

* HTML, CSS, JavaScript
* Highcharts
* SSB API
* ChatGPT API
* Google Maps API
